# 🚗 AUTOLOC

A AUTOLOC é uma plataforma automotiva desenvolvida com foco em praticidade, tecnologia e conectividade, permitindo que usuários encontrem oficinas, locadoras, estéticas automotivas e diversos serviços próximos através de geolocalização.

O projeto foi desenvolvido como parte de um Projeto Integrador, unindo desenvolvimento web, backend e banco de dados para criar uma solução moderna voltada ao setor automotivo.

---

# ✨ Funcionalidades

* 📍 Geolocalização de serviços automotivos
* 🔧 Busca por oficinas e empresas próximas
* 🚘 Sistema de divulgação automotiva
* 🏢 Área para empresas e parceiros
* 📱 Layout responsivo para celular, tablet e desktop
* 🎨 Interface moderna e intuitiva
* 🔒 Termos de uso e privacidade

# 🎯 Objetivo do Projeto

O objetivo da AUTOLOC é facilitar a conexão entre motoristas e empresas automotivas, oferecendo uma plataforma moderna, rápida e acessível para localização de serviços e divulgação automotiva.

---

# 📱 Responsividade

O sistema foi desenvolvido totalmente responsivo, adaptando-se para:

* Smartphones
* Tablets
* Notebooks
* Monitores Desktop

---

# 🔐 Segurança e Privacidade

A plataforma utiliza dados como CPF, CEP, CNPJ, telefone, e-mail e localização apenas para funcionamento do sistema e melhoria da experiência do usuário, seguindo práticas modernas de segurança digital.
